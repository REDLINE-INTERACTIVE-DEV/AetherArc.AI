# Aether v0.4 — AI Team App\n\nAether is the independent AI team application built by AetherArc, with Redline Interactive Development as the parent company. The Android client talks to this FastAPI backend.\n\n## Team\n- **ManagerAI** — receives the user request and coordinates the team.\n- **ReasonAI** — reasoning and analysis.\n- **CodeAI** — software engineering.\n- **ResearchAI** — web/news research and source synthesis.\n\n## Active orchestration\nWhen a model provider is configured, ManagerAI automatically sends every request to ReasonAI and conditionally delegates to CodeAI and/or ResearchAI based on the request. Specialist jobs run in parallel, then ManagerAI receives their reports and produces the final answer. Direct agent selection also works.\n\nThis is orchestration software, not a newly trained frontier model. The model provider supplies the underlying language model while Aether supplies the team roles, routing, memory/history and app experience.\n\n## Easiest model setup\n1. Copy `.env.example` to `.env`.\n2. Add a Groq API key as `GROQ_API_KEY`.\n3. Optionally change `GROQ_MODEL`.\n4. Start the backend.\n\nThe backend also supports any OpenAI-compatible endpoint or a local Ollama server. Keep all model/API secrets on the backend machine; never put them in the APK.\n\n## Start\n`python START_AETHER_SERVER.py`\n\nThe API listens on `0.0.0.0:8000`. The Android app can connect through the computer's LAN IP, for example `http://192.168.1.10:8000`, when both devices are on the same Wi-Fi. For public deployment, use an HTTPS server URL.\n\n## Android\nThe `mobile/` directory is a buildable Android client. GitHub Actions builds `app-debug.apk` automatically after Android-related changes.\n\n## ResearchAI\nResearchAI can use Google News RSS without credentials and can additionally use Google Custom Search when the optional CSE credentials are configured.\n\n## Architecture\n`Android APK -> FastAPI backend -> ManagerAI -> ReasonAI / CodeAI / ResearchAI -> model provider`\n\nThe planned future tool layer is `specialist -> Composio -> external services`. Composio credentials should remain server-side and must never be embedded in the APK.\n
